# เฟส 2: ตารางจริงและโมเดลต้นแบบ

ใช้โฟลเดอร์สั้น เช่น `E:\CMZ` เก็บ workspace และวิดีโอเดิมไว้ตามเดิม
คัดลอกเฉพาะไฟล์โค้ดใหม่จากชุดนี้ลงข้าง START_SCOUT_WINDOWS.bat ไม่ต้องคัดลอก environment หรือย้ายวิดีโอ

## เริ่มใช้

1. เปิด START_PHASE2_WINDOWS.bat ครั้งแรกติดตั้ง environment ใหม่ชื่อ .phase2_venv (แยกจาก scout/YOLO เดิม)
2. เปิดหน้า http://127.0.0.1:8503 ถ้าไม่เปิดเอง
3. Step 1 อัปโหลด CMZ_FEEDING_CONFIRMED.json ที่คุณตรวจแล้ว แล้วกด Import
4. Step 4 เปิดตารางจริงได้ทันที และกด Create new results ZIP แล้วดาวน์โหลด PHASE2_RESULTS.zip
   ตารางนี้นับเฉพาะช่วงที่ตรวจ ไม่ใช่เวลาทั้งคืน ช่องว่างหมายถึงไม่มีป้าย ไม่ใช่ไม่มีพฤติกรรม
5. Step 2 / Add crop เลือกคลิปกิน ปรับกรอบแดงให้ครอบสัตว์ทั้งช่วง สามารถใช้กรอบเดียวกับคลิปกินจากกล้องเดียวกันได้ หลังตรวจว่าครอบครบทุกคลิป
6. Step 2 / Add a new labeled interval เพิ่มตัวอย่างเดินจากคลิปที่เห็นจริงอย่างน้อย 3 ช่วง (เกณฑ์ขั้นต่ำเพื่อทดสอบโปรแกรม ไม่ใช่จำนวนเพียงพอทางสถิติ)
   เลือก Source video และ Motion candidates เปิดดูคลิป เลือกเฉพาะช่วงที่เห็นเดินต่อเนื่องด้วยแถบเวลา หากมีการเดินสลับหายจากภาพ ให้ตัดช่วงให้สั้นลง หรือเลือก Mixed
   วาดกรอบครอบการเคลื่อนที่ทั้งหมดในช่วงนั้น แล้ว Save human-reviewed interval
7. Step 3 Train behavior pilot ฝึก Random Forest บนคุณลักษณะการเคลื่อนไหวจาก optical flow จริง
   โมเดลนี้เป็นส่วนแยกพฤติกรรมต้นแบบ ไม่ใช่ YOLO และไม่ใช่ระบบพฤติกรรมอัตโนมัติที่ประเมินครบแล้ว
8. Step 5 ทดลองข้อเสนอของโมเดล ค่า activity ยังคง Unknown จนคนตรวจยืนยัน คะแนนโหวตของโมเดลไม่ใช่ความมั่นใจที่สอบเทียบแล้ว

## การตรวจชะมดด้วย YOLO

กรอบชะมด/ภาพว่างเดิมยังใช้ได้ เปิด MERGE_YOLO_WINDOWS.bat เพื่อรวมเฉพาะป้ายที่ตรวจแล้วจากหลาย scan ไปยัง scan ใหม่
โปรแกรมเก็บไฟล์ต้นฉบับทุกอัน หากข้อมูลฝึก/validation/test ไม่ผ่านเกณฑ์เดิม จะแจ้งว่า ready=false ไม่ข้ามเกณฑ์
หากพร้อม ใช้ TRAIN_YOLO_WINDOWS.bat แล้วใส่ data.yaml ที่ได้ จะแยกตรวจ GPU และใช้ชุดทดสอบตามโค้ดเดิม
คะแนนตรวจจับวัตถุไม่ใช่คะแนนจำแนกพฤติกรรม

## กติกาของผลลัพธ์

- Walking / Feeding = Active เฉพาะช่วงที่คนยืนยัน
- Resting / Sleeping = Inactive เฉพาะช่วงที่เห็นและมีหลักฐานพอ ไม่อนุมานจากการอยู่นิ่ง
- Not visible / Unknown / Other / Mixed = Unknown ในตารางสองสถานะ
- การเข้ากล่องและการหายจากทุกกล้องไม่ได้ยืนยันการนอน
- หากไม่พบคลิปพัก/นอน ช่องตารางเป็น not annotated และว่าง ไม่ใช่ 0 วินาที
- ไม่รวมเวลาจากหลายกล้องที่ซ้อนกันเป็นเวลาของสัตว์ตัวเดียว
- คลิปที่มาจากเหตุการณ์เดียวกัน หรือ clock block เดียวกันข้ามกล้อง จะอยู่กลุ่มเดียวกันก่อนแบ่งข้อมูล
- หากไม่สามารถมี test ที่แยกกลุ่มและมีทุกคลาส โมเดลยังฝึกแบบ pilot ได้ แต่ไม่แสดง accuracy/F1 จากข้อมูลฝึก
- เกณฑ์ทดสอบขั้นต่ำ 3 คลิปต่อคลาสใน train/test เป็นเพียง guard เพื่อทดสอบระบบ ไม่ยืนยันความน่าเชื่อถือทางวิจัย
- ต้องตรวจนาฬิกาชื่อไฟล์ก่อนใช้แบ่งกลุ่มจริง ชุด test ที่เคยประเมินแล้วจะไม่ถูกอ้างเป็นการทดสอบใหม่

ยังไม่ได้ประเมิน end-to-end YOLO → behavior อัตโนมัติ โค้ดไม่อ้างว่าสำเร็จแล้ว และไม่สร้างผลรันโครงการขึ้นมาเอง
ไฟล์ส่วนตัว วิดีโอ ป้าย และโมเดลจากเครื่องคุณไม่ถูกอัปโหลด GitHub อัตโนมัติ
