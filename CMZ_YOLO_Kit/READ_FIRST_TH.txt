CMZ — ชุดสำรวจคลิปและเตรียม YOLO
27 ตุลาคม 2026

ครั้งนี้เริ่มจากหาสัตว์ก่อน ไม่ต้องติดป้ายพฤติกรรมในโปรแกรมเดิมต่อ
โปรแกรมเดิมยังอยู่เหมือนเดิม ชุดนี้เป็นโฟลเดอร์ใหม่และใช้ port 8502

สิ่งที่ต้องทำตอนนี้ (ยังไม่ฝึก YOLO)
1. แตก ZIP เป็นโฟลเดอร์ใหม่ วางไว้ใกล้โฟลเดอร์ CMZ_Phase2_Kit_v1 เดิม
2. เปิด START_SCOUT_WINDOWS.bat
   ถ้าพบ environment เดิม จะใช้แพ็กเกจเดิมแบบอ่านอย่างเดียวโดยไม่ติดตั้งทับ
   ถ้าไม่พบ จะติดตั้งแพ็กเกจสำหรับสำรวจคลิปใน environment ใหม่ ไม่ใช้สิทธิ์ admin
   Python 3.12 แนะนำที่สุด ถ้าขึ้นถาม Email กด Enter ข้ามได้
3. เปิด http://127.0.0.1:8502 ถ้าหน้าเว็บไม่เปิดเอง
4. Step 1: วางที่อยู่โฟลเดอร์วิดีโอ เช่น E:\mod stardewS\test แล้วกด Find videos
5. เลือกไฟล์ที่มีอยู่ในเครื่อง เริ่มทีละไฟล์
   ใช้ Minutes to scan = 0 เพื่อสำรวจทั้งคลิป (เลขอื่นคือสำรวจเฉพาะต้นคลิปตามจำนวนนาที)
   ถ้าเลือกเพียงต้นคลิปแล้วไม่เห็นสัตว์ ไม่ได้แปลว่าทั้งคลิปไม่มีสัตว์
6. กด Start new scan แล้วกด Refresh status / results เพื่อดูความคืบหน้า
   สถานะ complete = สแกนจบ / error = ส่งภาพข้อความ error มา
   คลิปหลายชั่วโมงอาจใช้เวลานานและกินพื้นที่ภาพเพิ่ม ราว 100–250 MB ต่อชั่วโมงโดยประมาณ
   โปรแกรมอ่านวิดีโอและสร้างภาพใหม่ ไม่แก้ไข ย้าย หรือลบต้นฉบับ
7. Step 2: ดูภาพเรียง Highest motion first ก่อนเพื่อหาช่วงที่น่าตรวจ
   ภาพที่เคลื่อนไหวมากอาจเป็นเงา ใบไม้ คน หรือแสง ไม่ได้ยืนยันว่าเป็นชะมด
   ต้องดู Chronological ด้วย เพราะชะมดที่พักนิ่งอาจไม่อยู่ในกลุ่มเคลื่อนไหวมาก
   โปรแกรมเก็บภาพทุก 1 วินาที ถ้าโผล่สั้นกว่านั้นอาจพลาด ยังไม่รับประกันว่าหาครบ
8. เพื่อให้ฉันช่วยตรวจ: Step 4 → ติ๊ก Include overview images → Create review ZIP
   กด Download REVIEW.zip แล้วส่ง CMZ_REVIEW.zip กลับในแชทนี้
   ZIP มีภาพรวมตามเวลาและตามการเคลื่อนไหวอย่างละไม่เกิน 24 ภาพ กับตารางเวลาของภาพทั้งหมด
   ไม่มีวิดีโอต้นฉบับ การส่ง ZIP เป็นสิ่งที่คุณทำเอง โปรแกรมไม่อัปโหลดอัตโนมัติ
   ถ้า overview ยังไม่พบสัตว์ ต้องสำรวจหน้าต่อ/ช่วงอื่น ไม่สรุปว่าทั้งคลิปไม่มีสัตว์

เมื่อพบสัตว์แล้ว (ฉันจะช่วยแนะนำจากภาพจริง)
9. Step 2 กด Open full frame ที่ภาพสัตว์ชัด ใส่ชื่อผู้ตรวจ เช่น Wanikkasit
10. เลื่อน Left/right และ Top/bottom ให้กรอบแดงครอบตัวสัตว์ที่มองเห็น แล้ว Save civet + box
    ครอบตัวสัตว์ในภาพเต็ม ไม่ใช่ครอบทั้งห้อง และไม่ใช่ป้าย Active/Inactive
    โหมดนี้ออกแบบสำหรับชะมดหนึ่งตัวต่อภาพ ถ้ามีหลายตัว/ทับกันให้ uncertain ก่อน
11. Save verified empty ใช้เฉพาะภาพที่ตรวจแล้วว่าไม่มีตัวสัตว์ที่มองเห็นให้ตรวจจับ
    ถ้ามุมบัง ไม่แน่ใจ เล็กจนแยกไม่ออก หรืออาจมีสัตว์ในเงา ให้ Save uncertain / skip
    ภาพที่ยังไม่ตรวจและ uncertain จะไม่ถูกเอาไปเป็น negative อัตโนมัติ
12. ต้องมีภาพหลายท่า หลายช่วงเวลา ทั้งกลางวัน/กลางคืนถ้ามี และภาพฉากหลังว่างที่ตรวจแล้ว
    อย่าเก็บแต่หลายร้อยเฟรมติดกันจากการปรากฏตัวครั้งเดียวแล้วเรียกว่ามีข้อมูลหลากหลาย
13. Step 3 สร้าง dataset YOLO หลังตรวจนาฬิกาในภาพกับชื่อไฟล์/นาฬิกาทุกกล้อง
    ระบบแบ่งเป็น recording-time blocks 30 นาทีร่วมกันทุกกล้อง กันขอบ 15 วินาที
    train/validation/test ถูกกำหนดด้วย hash คงที่ ไม่เลือก seed ตามคะแนน
    ข้อมูลวันเดียวสัตว์ตัวเดียวและ blocks ใกล้กันยังมีความสัมพันธ์ ผลไม่แทนวัน/สัตว์อื่น
    ก่อน export ต้องมีอย่างน้อย train 20 positives, val/test อย่างละ10 positives
    ทุก split มีอย่างน้อย5 verified empty และ2 blocks
    นี่เป็นเกณฑ์ขั้นต่ำของโปรแกรม ไม่ใช่หลักฐานว่าข้อมูลพอหรือโมเดลจะแม่น
    ถ้าไม่พอให้ส่ง ZIP มา ไม่แก้ป้ายให้ครบจำนวน ไม่คัด test ตามคะแนน

ฝึก YOLO (ยังไม่ต้องทำตอนนี้)
14. TRAIN_YOLO_WINDOWS.bat จะถามให้พิมพ์ YES ก่อนติดตั้ง YOLO ใน .yolo_venv ใหม่
    การติดตั้งอาจดาวน์โหลดแพ็กเกจขนาดใหญ่ ไม่แก้ environment โปรแกรมเดิมหรือ driver
    ถ้า PyTorch ยังใช้ GPU ไม่ได้ จะสร้าง GPU_INFO.txt ให้ส่งมาและหยุดได้
    อย่าเพิ่งเลือก CPU ถ้าอยากใช้ RTX3070 ให้ฉันตรวจ GPU_INFO.txt ก่อน
15. วาง path ของ data.yaml ที่ Step3 สร้าง โปรแกรม fine-tune YOLO11n pretrained บนคลาส civet
    50 epochs, early stopping patience10, batch4, imgsz640, seed42, workers0
    batch4เป็นจุดเริ่มต้น ไม่รับประกันว่าจะพอดีกับ VRAM ทุกสภาพเครื่อง
    YOLO11n เป็นรุ่นเริ่มต้นที่เอกสารทางการยังรองรับ ไม่ได้อ้างว่าเป็นรุ่นล่าสุดหรือดีที่สุด
16. ใช้ validation เลือก best weights แล้วประเมิน test ครั้งเดียว
    รายงาน precision/recall/mAP และ confusion matrix สำหรับการตรวจจับ
    คะแนนตรวจจับไม่ใช่คะแนน Active/Inactive และไม่มีผลจริงให้จนกว่าจะรันข้อมูลจริง
17. หลังตรวจ detector แล้ว จึงใช้มันช่วยค้นหาช่วงสัตว์ในวิดีโออื่น และตรวจพฤติกรรมตามเวลา
    ต้องสุ่มตรวจช่วงที่ไม่พบด้วย เพราะ detector อาจพลาด
    ยังต้องทำส่วน Active/Inactive และประเมิน behavior แยกเพื่อให้งานครบโจทย์

สถานะที่ต้องเข้าใจให้ตรงกัน
- ชุดนี้ทำส่วนสำรวจคลิป วาดกรอบ ส่งออก YOLO dataset และเตรียมคำสั่งฝึก detector
- ยังไม่มีโมเดลชะมดที่ฝึกแล้ว ยังไม่พบ/ยืนยันว่าคลิปใดเหมาะสำหรับฝึกจากชุดกล้องทั้งหมด
- ส่วนค้นหาวิดีโออัตโนมัติด้วย detector และ behavior pipeline จะต่อหลังได้ข้อมูลและผล detector จริง
- ยังไม่มีผลโปรเจกต์ คะแนนจริง สไลด์สรุปผล หรือ GitHub/annotation URL
- ไม่ใช้ภาพ AI mock ไม่ถือ motion score เป็นป้ายสัตว์ ไม่ถือห้องว่างเป็น Inactive
- เก็บข้อมูลเดิมไว้ การทดลองครั้งใหม่หลังเห็น test ต้องกัน test ใหม่จริง
- ชุดใหม่แยกจากเดิม และการแบ่งข้อมูลใช้หลักเวลาเดียวกับเดิมเพื่อกันเวลาทับข้ามกล้อง

ถ้าติดปัญหา: ส่งภาพหน้าจอหรือ CMZ_REVIEW.zip มาได้ ไม่ต้องเขียนโค้ดเอง
